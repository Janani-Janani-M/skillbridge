# Feature summary

**Student:** self-registration, profile and proficiency, opportunity search/filter/sort/page, role bookmarks, academic eligibility, one application per role, snapshot/coverage, status/interview timeline, notifications, withdrawal/offer decision, password update and private CSV export.

**Placement office:** pipeline dashboard, opportunity and skill administration, student directory, applicant review and status change, interview scheduling, audit history, CSV reports, descriptive coverage statistics and an explicitly hypothetical binomial lab.

**Technical:** Java 17 and JDBC; normalized embedded H2 SQL; constraints, FKs, transactions and versioned updates; password hashing, random sessions, CSRF/role checks, escaped local HTML, responsive CSS, synthetic seed data and offline deterministic Java tests.
